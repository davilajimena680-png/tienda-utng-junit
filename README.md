# Tienda UTNG

![Java](https://img.shields.io/badge/Java-17-blue)

Proyecto desarrollado en Java aplicando Programacion Orientada a Objetos, JDBC, Clean Code y principios SOLID.

## Caracteristicas

- Modelo Producto
- Conexion a MySQL
- DAO con CRUD
- Capa de servicio
- Demo desde Main

## Ejecucion

Compilar y ejecutar:

```bash
javac src/**/*.java
java src/Main
```
